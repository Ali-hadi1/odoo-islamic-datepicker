Hijri/Qamari Date Picker

The Islamic Date Picker (Hijri/Qamari) module in Odoo is designed to provides the ability to display and pick dates using Hijri/Qamari calendars in the Odoo web client. Integrates a Islamic date conversion library and a Islamic date picker widget to show non‑Gregorian equivalents alongside standard Gregorian dates, allow input in these calendars, and perform correct conversion for date fields. (Hijri/Shamsi field data is not stored in database)
